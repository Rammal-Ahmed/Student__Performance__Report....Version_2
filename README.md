# Student__Performance__Report....Version_2

A Python project that turns subject marks into a clear student performance summary

## Overview

The Student Performance Report takes a student's details and marks in five subjects, then calculates the key results and presents them in a readable report. The project is part of my Python practice, with a focus on calculations, conditional statements, and presenting output neatly.

## Features

- Accepts student name and roll number
- Records marks for five subjects
- Calculates total marks, average, and percentage
- Identifies the highest and lowest subject marks
- Assigns a grade based on percentage
- Determines the overall pass or fail result
- Displays the results in a structured console report

## Technologies Used

- Python 3
- User input and output
- Arithmetic operations
- Built-in `max()` and `min()` functions
- `if`, `elif`, and `else` statements
- String formatting

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run the following command in the terminal:

   `python student_performance_report.py`

5. Enter the student's details and subject marks when prompted.
